# v0.7.0

## 版本性质
主版本。

## 版本定位
这是“会话从前台 CLI 进入后台运行时”的版本。

## 本版目标
建立后台会话与恢复能力，实现：
- 守护进程；
- 后台任务；
- 会话附着；
- 会话恢复。

## 为什么这一版重要
如果没有后台会话，产品仍然更像“这次命令做完就结束的 CLI 工具”；
有了后台会话后，产品才真正有长期任务和持续协作的味道。

## 对齐参考仓库的重点
重点参考：
- `claude-code-fork/src/entrypoints/cli.tsx`
- `claude-code-fork/src/main.tsx`
- `claude-code-fork/src/QueryEngine.ts`

## 本版要做什么
### 1. 新增守护进程入口
新增：
- `packages/cli/src/entrypoints/daemon.ts`
- `packages/cli/src/entrypoints/attach.ts`
- `packages/cli/src/entrypoints/resume.ts`

### 2. 新增后台会话运行时
新增：
- `packages/core/src/session/runtimeStore.ts`
- `packages/core/src/session/runtimeTypes.ts`
- `packages/core/src/session/recover.ts`

### 3. 升级 Session Storage
需要同时保存：
- 消息历史；
- 当前权限模式；
- 最近计划；
- 最近输出位置；
- 当前任务状态。

### 4. CLI 支持查看与附着
目标：
- 查看已有会话；
- 附着到某个会话继续看输出；
- 中断后可恢复；
- 结束后能清理状态。

## 本版结束后的产品状态
- 产品第一次具备“任务不跟着当前终端一起死”的能力；
- 更接近长期协作工具，而不是短命 CLI；
- 为复杂任务和多 Agent 打开空间。

## 是否已可用
- 对你自己：是，且适合更复杂任务。
- 对小范围试用：是。
- 对更多用户：还需要更高阶能力与工程化收口。

## 本版主要学习目标
- 理解会话存储和会话运行时不是一回事；
- 学会把前台交互层和后台执行层拆开；
- 学会为恢复设计真正可工作的状态模型。

## 本版能学到的技术点
- 如何设计守护进程入口、附着模式和恢复模式，让 CLI 从前台工具升级为后台运行时；
- 如何区分 session storage 和 runtime state，避免“能恢复历史”误当成“能恢复运行”；
- 如何保存任务状态、权限模式、最近计划和输出位置，支持真正可用的恢复；
- 如何设计 attach / resume 这种终端产品常见的会话交互能力；
- 如何让长任务不依赖当前终端窗口，从而支撑更复杂的 Agent 工作流。

## 本版不要做什么
- 不做子 Agent；
- 不做工作树隔离；
- 不做高级上下文压缩；
- 不做复杂远程控制；
- 不做桌面端托盘。
