# v0.6.0

## 版本定位
这是“会话系统从前台走向后台”的版本。

参考项目里，后台会话、恢复、守护进程，不只是高级功能，它们让 Agent 真正摆脱“一次性前台命令”的限制。

## 本版目标
建立后台会话能力，实现：
- 会话可脱离前台持续运行；
- 可重新附着查看输出；
- 可恢复未完成任务；
- 有基础守护进程。

## 对齐参考仓库的重点
重点参考：
- `claude-code-fork/src/entrypoints/cli.tsx`
- `claude-code-fork/src/main.tsx`
- `claude-code-fork/src/QueryEngine.ts`

本版重点学“session runtime”和“前后台分离”，不追求复杂远程控制。

## 本版要做什么
### 1. 新建后台会话运行时
建议新增：
- `packages/core/src/session/runtimeStore.ts`
- `packages/core/src/session/runtimeTypes.ts`
- `packages/core/src/session/recover.ts`

### 2. 新建守护进程入口
建议新增：
- `packages/cli/src/entrypoints/daemon.ts`
- `packages/cli/src/entrypoints/attach.ts`
- `packages/cli/src/entrypoints/resume.ts`

### 3. 支持后台任务最小控制
建议第一版支持：
- 启动后台任务；
- 查看任务列表；
- 重新附着输出；
- 终止任务。

### 4. Session Storage 升级
不再只存会话消息，还要存：
- 运行状态；
- 最近输出位置；
- 当前权限模式；
- 最后一次恢复点。

## 建议目录形态
```text
packages/core/src/
├─ session/
│  ├─ storage.ts
│  ├─ runtimeStore.ts
│  ├─ runtimeTypes.ts
│  └─ recover.ts
└─ app/
   └─ queryEngine.ts

packages/cli/src/
├─ entrypoints/
│  ├─ cli.ts
│  ├─ daemon.ts
│  ├─ attach.ts
│  └─ resume.ts
└─ render/
```

## 关键代码任务
- `QueryEngine` 需要支持暂停与恢复；
- 流式输出要能落到后台缓存；
- CLI 需要能附着到已有 session；
- session 恢复不能只恢复文本，还要恢复执行状态。

## 本版结束后的产品状态
- 产品不再被前台终端生命周期绑定；
- 能开始承载更长任务、更复杂任务；
- 与参考项目的“长期会话工具”定位更加一致。

## 本版主要学习目标
- 理解会话持久化和会话运行时是两回事；
- 学会把前台交互和后台执行拆开；
- 学会为“恢复”设计状态，而不是只保存日志。

## 本版不要做什么
- 不做远程 Web 控制台；
- 不做云端同步；
- 不做多机协作；
- 不做复杂权限租约；
- 不做桌面端托盘功能。
