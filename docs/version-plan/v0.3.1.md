# v0.3.1

> 学习基线说明：本版本仍是未来计划。完成 `v0.3.0` 的学习验收后再进入。

## 版本性质
补丁版本。

## 版本定位
这是第一版“安全改动可用版”。

## 本版目标
不增加新的能力边界，只把 `v0.3.0` 的执行链路打磨到你能在真实开发中谨慎使用的程度。

## 这一版为什么重要
只读产品不稳定，问题只是回答差；
执行产品不稳定，问题会变成：
- 改错文件；
- 命令跑错；
- 拒绝/确认流程混乱；
- 执行失败无法解释。

所以这版必须单独收口。

## 本版要做什么
### 1. 稳定权限交互
要求：
- `allow / ask / deny` 路径都可测；
- 拒绝后能正确回填模型；
- REPL 中连续确认不会打乱会话状态。

### 2. 稳定 Plan -> Execute 链路
要求：
- 计划结构可复用；
- 批准后能真正驱动执行；
- 计划失败与执行失败能区分开。

### 3. 稳定写入与命令执行
优化：
- `write_file` 路径边界；
- `diff` 展示质量；
- 命令超时与中断；
- 白名单匹配逻辑；
- 错误返回文案。

### 4. 增加执行类回归测试
建议至少覆盖：
- 计划模式下只允许只读工具；
- 拒绝写入后模型收到拒绝结果；
- 白名单命令可执行；
- 非白名单命令被拒绝；
- 写入后文件内容符合预期。

### 5. 优化交互文案
要求：
- 确认提示说清楚会改什么、跑什么；
- 错误提示说清楚失败在哪一步；
- 最终回答能把“计划、执行、验证”串起来。

## 本版结束后的产品状态
- 这是第一版可以在你自己的真实开发里谨慎使用的 CLI Agent；
- 它已经不只是“会解释代码”，而是能参与小范围开发闭环；
- 可以作为后续更强能力的稳定基底。

## 是否已可用
- 对你自己：是，已经可以进入真实使用。
- 对少量熟悉工程的人：可以试用。
- 对普通用户：还不建议。

## 本版主要学习目标
- 理解为什么危险能力一定要有独立稳定化阶段；
- 学会给执行链路做回归测试；
- 学会把“能做”收口为“可安全使用”。

## 本版能学到的技术点
- 如何为权限链路写回归测试，覆盖允许、拒绝、确认和连续确认场景；
- 如何稳定 Plan -> Approve -> Execute 的状态切换，避免会话状态错乱；
- 如何收紧写入和命令执行边界，降低误改文件和误跑命令的风险；
- 如何让执行失败被模型正确理解并继续协作，而不是直接中断用户流程；
- 如何把“危险功能可用”进一步收口成“危险功能可谨慎日常使用”。

## 本版不要做什么
- 不新增新工具种类；
- 不加流式输出；
- 不加上下文系统；
- 不加 provider 适配层；
- 不改工程形态。
