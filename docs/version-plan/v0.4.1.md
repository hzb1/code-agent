# v0.4.1

## 版本性质
补丁版本。

## 版本定位
这是“个人主力可用版”。

它不增加新的能力边界，而是把 `v0.4.0` 已经具备的体验和上下文能力打磨到你可以长期日常使用的程度。

## 本版目标
把下面几条链路彻底收口：
- 流式输出稳定；
- 打字机效果稳定；
- 上下文构建稳定；
- 多轮会话下的计划、执行、记忆衔接稳定。

## 为什么这一版是关键可用里程碑
`v0.3.1` 虽然已经能改代码，但体验和上下文仍然偏“工具化”；
到 `v0.4.1`，产品应当具备：
- 更顺滑的持续对话；
- 更稳定的上下文继承；
- 更明确的状态反馈；
- 更像一个日常可用 Agent 的整体感。

## 本版要做什么
### 1. 稳定流式反馈
优化：
- 流式结束信号；
- 中断后的恢复；
- 工具执行时的状态渲染；
- 多段输出的换行与清屏策略。

### 2. 稳定上下文构建
优化：
- 避免重复注入同一规则；
- 避免最近文件摘要与原始消息冲突；
- 避免会话越长越容易跑偏；
- 计划结果和权限状态在后续轮次里继续生效。

### 3. 增加上下文与流式回归测试
建议覆盖：
- 多轮连续规划与执行；
- 会话恢复后的上下文重建；
- 流式输出中途工具调用；
- 打字机关闭与开启两种模式。

### 4. 收口终端体验细节
优化：
- REPL 提示符；
- 成功/失败状态摘要；
- 打字机开关配置；
- 错误时的结束提示。

## 本版结束后的产品状态
- 这是第一版你可以长期日常使用的 CLI Agent；
- 它已经有“持续协作工具”的感觉，而不只是一个命令行脚本集合；
- 后续可以开始做更深的系统升级，而不是只盯着体验补洞。

## 是否已可用
- 对你自己：是，已经可以作为主力 CLI Agent 使用。
- 对熟悉命令行的开发者：可以试用。
- 对更广泛用户：等工程化版本更稳后再放开。

## 本版主要学习目标
- 理解“可长期使用”和“功能存在”之间的差别；
- 学会给上下文系统做稳定化；
- 学会给流式交互做细节收口。

## 本版不要做什么
- 不新增新模块；
- 不加 provider 兼容层；
- 不加 MCP / Skills；
- 不改工程分包结构；
- 不做后台会话。
