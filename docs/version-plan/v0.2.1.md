# v0.2.1

## 版本性质
补丁版本。

## 版本定位
这是第一版“可以给人用”的版本，但范围只限于只读代码理解和项目问答。

## 本版目标
不增加新的产品能力，只把 `v0.2.0` 的只读链路打磨到可试用状态。

## 这一版为什么重要
如果 `v0.2.0` 做完就直接往下加写入和执行能力，很容易把一套“不稳的只读基础”带进更危险的执行阶段。

所以这版的目标很明确：
- 只读链路先稳；
- REPL 先稳；
- 会话恢复先稳；
- doctor 先稳。

## 本版要做什么
### 1. 稳定检索结果质量
优化：
- `list_files` 的目录深度与忽略规则；
- `search_files` 的结果数、摘要长度、排序；
- `read_file` 的截断提示与错误说明。

### 2. 稳定 REPL 交互
优化：
- 空输入处理；
- 中断恢复；
- 连续追问时历史保留；
- 错误不退出整个 REPL。

### 3. 稳定 session 恢复
要求：
- 最近一次会话可恢复；
- 恢复后历史可继续参与回答；
- 存储损坏时给清晰提示，不要直接崩溃。

### 4. 增加只读回归测试
建议至少覆盖：
- “入口文件在哪”；
- “这个项目做什么”；
- “帮我找某个关键词在哪”；
- REPL 连续两轮追问。

### 5. 收口用户提示文案
错误提示要做到：
- 中文；
- 可操作；
- 明确是配置问题、网络问题、模型问题还是工具问题。

## 建议目录形态
目录不新增大模块，保持：

```text
src/
├─ cli/
├─ app/
├─ session/
├─ tools/
└─ loop/

tests/
├─ unit/
├─ integration/
└─ e2e/
```

## 关键代码改动点
重点会动：
- `src/tools/listFiles.ts`
- `src/tools/searchFiles.ts`
- `src/tools/readFile.ts`
- `src/cli/repl.ts`
- `src/session/storage.ts`
- `src/cli/doctor.ts`

重点会新增：
- `tests/e2e/readOnlyRepl.test.ts`
- `tests/integration/searchAndRead.test.ts`

## 本版结束后的产品状态
- 这是第一版真正可用的产品；
- 虽然还只能只读，但已经可以让人稳定拿它做代码理解、结构定位、项目问答；
- 可以开始给少量人试用。

## 是否已可用
- 对你自己：是。
- 对 1-2 个试用者：是。
- 对更广泛用户：还不建议。

## 本版主要学习目标
- 理解“可用”不只是功能存在，而是交互稳定；
- 学会给一个只读产品做第一轮收口；
- 学会把补丁版本用在体验和稳定性上。

## 本版不要做什么
- 不新增新工具；
- 不加写文件；
- 不加命令执行；
- 不加权限系统；
- 不加流式输出。
