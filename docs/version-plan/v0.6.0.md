# v0.6.0

## 版本性质
主版本。

## 版本定位
这是“从单包产品升级为可扩展工程”的版本。

## 本版目标
同时完成两件重要升级：
- Core 抽离与包结构升级；
- MCP / Skills / 扩展能力基础。

## 为什么把这两件放在一起
因为只有先把 core 抽出来，MCP 和 Skills 才不会把 CLI 壳层、Loop、Tool System、Context 搅在一起。

## 对齐参考仓库的重点
重点参考：
- `claude-code-fork/src/main.tsx`
- `claude-code-fork/src/tools.ts`
- `claude-code-fork/CLAUDE.md`
- `claude-code-fork/docs/`

## 本版要做什么
### 1. 抽离 `packages/core` 与 `packages/cli`
建议目录：

```text
packages/
├─ core/
│  └─ src/
│     ├─ app/
│     ├─ loop/
│     ├─ tools/
│     ├─ permissions/
│     ├─ prompt/
│     ├─ context/
│     ├─ llm/
│     └─ core/
└─ cli/
   └─ src/
      ├─ entrypoints/
      ├─ repl/
      └─ render/
```

### 2. 抽出 core 公共 API
要求：
- CLI 只依赖 core 暴露的接口；
- core 不依赖 CLI；
- 类型边界清晰；
- 避免循环依赖。

### 3. 增加 MCP 接入层
新增：
- `packages/core/src/mcp/client.ts`
- `packages/core/src/mcp/types.ts`
- `packages/core/src/mcp/registry.ts`

### 4. 增加 Skills 接入层
新增：
- `packages/core/src/skills/loader.ts`
- `packages/core/src/skills/resolve.ts`
- `packages/core/src/skills/types.ts`

### 5. 扩展 Tool Registry
Registry 要支持三类来源：
- 内建工具；
- MCP 工具；
- Skill 驱动的扩展上下文或能力。

## 关键代码改动点
重点会动：
- 原 `src/` 下大多数核心模块；
- CLI 入口与 REPL；
- Tool Registry；
- Context 构建。

重点会新增：
- `packages/core/*`
- `packages/cli/*`
- `packages/core/src/mcp/*`
- `packages/core/src/skills/*`

## 本版结束后的产品状态
- 产品具备真正的“core + shell”工程结构；
- 内建能力之外，开始具备扩展接口；
- 后续做后台会话和多 Agent 时，边界会健康很多。

## 是否已可用
- 对你自己：是。
- 对小范围试用：是。
- 对更广泛用户：还需后台能力和工程化能力更稳。

## 本版主要学习目标
- 理解为什么成熟 Agent 产品必须有稳定的 core 边界；
- 理解扩展体系为什么必须服从同一套工具、权限、上下文规则；
- 学会在“不做生态”的前提下给未来留接口。

## 本版不要做什么
- 不做插件市场；
- 不做后台会话；
- 不做子 Agent；
- 不做复杂云端扩展系统；
- 不做桌面端。
