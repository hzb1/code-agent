# v0.8.0

## 版本性质
主版本。

## 版本定位
这是“复杂任务能力”和“长会话稳定性”同时升级的版本。

## 本版目标
同时完成两组高级能力：
- 子 Agent、协调与工作树隔离；
- 高级上下文管理、预算、摘要、恢复重建。

## 为什么把这两组放在一起
因为子 Agent 一旦出现，系统马上会面对：
- 上下文分配；
- 结果聚合；
- 长历史压缩；
- 恢复时的上下文重建。

这两块如果分开做，会让系统长期处在“不够稳”的中间状态。

## 本版要做什么
### 1. 新增子 Agent 管理模块
新增：
- `packages/core/src/agents/manager.ts`
- `packages/core/src/agents/worker.ts`
- `packages/core/src/agents/types.ts`
- `packages/core/src/coordination/planner.ts`
- `packages/core/src/coordination/aggregate.ts`

### 2. 增加工作树或隔离执行环境抽象
新增：
- `packages/core/src/git/worktree.ts`
- `packages/core/src/git/sandbox.ts`

即使第一版不做完整 git worktree，也必须先把“隔离执行”抽象出来。

### 3. 新增上下文预算与压缩模块
新增：
- `packages/core/src/context/budget.ts`
- `packages/core/src/context/policy.ts`
- `packages/core/src/context/compaction.ts`
- `packages/core/src/context/summary.ts`
- `packages/core/src/context/recentFiles.ts`

### 4. 恢复时重建上下文快照
要求：
- 恢复不是把所有原始消息再塞回去；
- 而是重建“当前可工作的上下文快照”；
- 支持主 Agent 和子 Agent 场景。

## 本版结束后的产品状态
- 产品开始能处理更复杂的任务拆分；

## 是否已可用
- 对你自己：是，适合复杂项目。
- 对小范围高阶用户：可以试用。
- 对更广泛用户：需要工程化和发布能力收口。

## 本版主要学习目标
- 理解复杂任务拆分的真正难点是上下文和权限；
- 学会给子 Agent 设计边界和结果聚合；
- 学会给长会话设计预算、摘要和恢复策略。

## 本版能学到的技术点
- 如何设计子 Agent 管理器、任务协调器和结果聚合器；
- 如何把复杂任务拆分成可独立执行、可汇总的多个子任务；
- 如何抽象工作树或隔离执行环境，为并行修改和安全执行预留基础；
- 如何做上下文预算、摘要压缩和最近文件策略，支撑超长会话；
- 如何在恢复时重建“可工作的上下文快照”，而不是简单重放全部历史。

## 本版不要做什么
- 不做完全自动 swarm；
- 不做无人监管的并发改代码；
- 不做云端多机 agent 集群；
- 不做商业级任务编排平台；
- 不做桌面端。
