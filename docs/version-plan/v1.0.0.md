# v1.0.0

## 版本性质
完成版主版本。

## 版本定位
这是“参考项目同类 CLI 产品完成版”。

这里的“完成”，不是说项目以后不再演进，而是说：
- 参考项目最重要的核心骨架已经具备；
- 参考项目最重要的核心能力已经具备；
- 产品已经形成一个完整、可长期使用、可继续演进的本地 CLI Coding Agent。

## `1.0.0` 的产品定义
这是一个：
- 面向开发者的本地 CLI Agent；
- 支持多轮对话、规划、执行、验证；
- 有权限模型、Plan Mode、流式反馈、上下文系统；
- 有工具编排、Provider 适配、扩展能力、后台会话、子 Agent、工程化体系；
- 已经可以作为 Claude Code / Codex 同类 CLI 产品使用。

## 最终核心代码角色
### 1. Entrypoints
负责：
- 启动 CLI；
- 分发不同命令模式；
- 连接普通运行、REPL、doctor、daemon、resume、attach。

### 2. QueryEngine
负责：
- 管理会话生命周期；
- 管理计划状态；
- 管理权限模式；
- 管理上下文构建；
- 协调 provider、tool system、session runtime。

### 3. QueryLoop
负责：
- 跑单轮 Agentic Loop；
- 请求模型；
- 接收流式事件；
- 发起工具调用；
- 根据结果决定继续还是停止。

### 4. Tool System
负责：
- 工具协议；
- 工具注册；
- 权限判断；
- 工具编排；
- 进度事件；
- 历史记录。

### 5. Context System
负责：
- 系统提示；
- 项目规则；
- 项目记忆；
- 会话记忆；
- 计划与权限状态；
- budget、摘要、压缩、恢复。

### 6. Provider Layer
负责：
- 统一不同模型厂商；
- 统一消息格式；
- 统一流式事件；
- 统一错误模型。

## `1.0.0` 完成后的产品状态
- 你已经不再是在模仿参考项目做一个原型；
- 你已经做出一个完整的同类 CLI 产品；
- 这个产品足以支撑你继续走向更高阶的 Codex / Claude Code 风格产品线。

## `1.0.0` 主要学习收获
- 学会如何设计一个本地 AI Coding Agent；
- 学会如何把会话、循环、工具、权限、上下文、provider 解耦；
- 学会如何从大参考项目中提炼骨架，而不是只模仿表面功能；
- 学会如何把原型一步步长成系统工程。

## `1.0.0` 之后先不要急着做什么
- 不急着做桌面端；
- 不急着做云服务；
- 不急着做商业化；
- 不急着做跨平台 GUI；
- 先把 CLI 产品打磨稳定，再决定下一个产品线。
